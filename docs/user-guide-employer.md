# Employer User Guide

## 1) Register and Login
1. Open `/register/employer`.
2. Submit account and initial company details.
3. You are redirected to employer dashboard after successful registration.
4. Returning users login via `/login`.

## 2) Maintain Company Profile
1. Go to `Dashboard -> Company Profile`.
2. Create/update company information (name, description, address, website, contact).
3. Save and verify updated values.

## 3) Manage Jobs
1. Go to `Dashboard -> Manage Jobs`.
2. Create a new posting from `Post New Job`.
3. Fill required fields and set status (`draft`, `published`, `closed`) plus public visibility.
4. Edit existing jobs from the job list.

## 4) Review Applicants Per Job
1. Open `Manage Jobs`.
2. Choose a job and open applicants view.
3. Review application status, ATS progress, and ranking signals where available.

## 5) View Endorsed Candidates
1. Open a job’s endorsed candidates view.
2. See staff-endorsed applicants and endorsement notes/timestamps.

## 6) Matching Support in Employer Views
- Ranked applicant lists are available per job.
- Each entry includes score and simple explanation summary.
- Reviewers can record explicit human review actions and notes.
- Review timeline can be opened per applicant.
- CSV review summary export is available for governance/audit preparation.
- Scores are decision-support signals only; no automatic hiring actions are executed.

## 7) Access Rules
- Employers can only access jobs and applicant data linked to their own company/jobs.
- Cross-company data access is blocked by backend role/ownership checks.
