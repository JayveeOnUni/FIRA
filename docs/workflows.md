# User Roles and High-Level Workflows

## 1. Applicant Workflow
1. Visit public pages and search jobs.
2. Register and authenticate account (planned).
3. Complete profile and upload required documents/resume.
4. Submit application for selected jobs.
5. Monitor ATS status updates from submitted applications.
6. Receive notifications for status changes or required actions.

## 2. Employer Workflow
1. Register and authenticate employer account (planned).
2. Create and maintain company profile.
3. Post job vacancies and define candidate requirements.
4. Review candidate lists (manual and AI-assisted in later phases).
5. Coordinate with agency staff on endorsed candidates.

## 3. Agency Staff Workflow
1. Access staff dashboard for active recruitment overview.
2. Verify applicant documents/profile completeness.
3. Review and manage job vacancies from employers.
4. Update ATS stages for each application.
5. Endorse candidates and maintain operational notes.
6. Generate operational reports (planned in later phases).

## 4. Layer Mapping
- **Public Website Layer:** discovery and onboarding entry points.
- **Recruitment Management Layer:** applicant/employer/staff actions and ATS tracking.
- **Intelligent Matching Layer:** recommendation support for ranking and shortlisting.
