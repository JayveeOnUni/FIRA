# FIRA Client (Phase 3)

## Implemented
- Public website pages (Home, About, FAQ, News, Contact, Job Search)
- Auth pages (Login, Applicant Register, Employer Register)
- Job detail page with applicant apply action
- Applicant profile, documents, and applications pages
- Employer company profile and job management pages
- Auth bootstrap using backend `auth/me`

## Commands
```bash
npm install
npm run dev
npm run lint
npm run build
```
